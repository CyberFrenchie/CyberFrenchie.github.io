This site does not use analytics, advertising pixels or tracking cookies.

The CVE page can request public records from the CVE Program API and the US National Vulnerability Database when you use it. Those requests are made directly from your browser to the relevant public service. Their own logs and privacy terms apply.

The site is hosted through GitHub Pages. GitHub may process standard web-server information needed to deliver the site. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.

No contact form is provided. If you follow an external GitHub or LinkedIn link, you leave this site and the destination's privacy terms apply.
